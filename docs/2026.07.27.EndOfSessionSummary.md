## Executive Summary
Tested Phase 1 of the Software Factory end-to-end and found the core gap: triage classified feedback correctly but nothing advanced the GitHub label (the state machine never transitioned). Fixed it by adding a trusted state-transition step, then converted the repo into its own installable plugin marketplace so every dev iteration is testable the same way it runs on Nuclaw. Full pipeline verified live on issues #1–#3. Committed as one commit and merged to `main` (fast-forward, pushed).

## Changes Made
- `.claude-plugin/marketplace.json` (new) — repo is its own single-plugin marketplace; installable by local path or `kilo9alfa/softwarefactory` from GitHub
- `.claude-plugin/plugin.json` — cleaned to standard schema (removed non-standard commands/scripts/config arrays); commands auto-discovered from `commands/`
- `commands/sf-triage.md` — added frontmatter (description + argument-hint); fixed arg placeholder `{{{issue_number}}}` → `$1`
- `scripts/sf-apply-label.sh` (new) — trusted state-transition step: extracts classifier JSON (fenced-block or fallback), validates classification is exactly `bug|feature|spam`, swaps label, rewrites title, posts rationale comment, closes spam; idempotency guard skips issues no longer in `feedback/triage`
- `scripts/sf-dispatcher.sh` — calls namespaced `/softwarefactory:sf-triage` and runs sf-apply-label.sh after triage in the tmux chain
- `scripts/sf-dev-sync.sh` (new) — reinstall plugin from working tree so command edits propagate past the version-pinned install cache
- `CLAUDE.md` — documented install + the dev loop
- `docs/` — design doc + docs README added to the commit
- Git: branch `phase1-installable-plugin`, commit `8fae5e5`, fast-forward merged to `main` and pushed; branch deleted local+remote

## Key Decisions
- **Label swap belongs in the dispatcher/helper, not the skill.** Keeps the untrusted classification advisory; the trusted component validates the value before touching state. This is why the pipeline stayed correct even when the skill emitted extra prose instead of "JSON only".
- **Local-path marketplace for dev, GitHub for prod.** Local install is testable without pushing; GitHub install is the Nuclaw path.
- **Documented the refresh gotcha** rather than trying to make edits live — `install` caches a version-pinned copy; only uninstall+reinstall re-syncs command files.
- Branched instead of committing to `main` directly (per workflow), then ff-merged.
